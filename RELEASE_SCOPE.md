# Release scope · 0.1.0

This is the first runnable beginner release of the personal Mandarin platform. It implements a coherent study loop instead of pretending the entire five-year learning journey has been authored and validated.

## Delivered

Twenty foundation/everyday lessons, 78 phrases, 348 activity steps, persistent independent-modality FSRS review, two bounded conversation rehearsals, one original three-pass audio scene, local media import and captions, tone models, recording/replay, dictionary, adaptive time allocation, progress evidence, offline bundled synthetic audio and transactional backups.

English instructions are implemented. Vietnamese glosses exist in the content model; there is no completed Vietnamese instructional course or independently validated L1-specific pedagogy. The advanced pathway is explicitly a roadmap, not playable lessons. The dictionary is a course lexicon, not a comprehensive reference dictionary.

## Content quality gate

All seed lessons and phrases are AI-assisted drafts. CC-CEDICT exact-entry references were collected for 48 of 78 items; composed expressions need constituent and contextual review. Dictionary agreement does not validate naturalness. The original scripts and both synthetic voices need Mandarin educator review for lexical/sandhi tones, prosody, register, segmentation and meaning. No native review, listening panel or learner pilot has been simulated.

Before publishing a content pack: record reviewer identity/date/version; resolve language issues; listen to each clip; verify answer distractors and transcript exposure; test new-speaker and unseen-scenario assessments; mark published only after linguistic, teaching, audio and assessment review.

## Next product increments

1. Harden the beginner course with educator review, recorded native voices, richer meaningful response exercises and observed beginner sessions. Current lesson time estimates are planning suggestions; ten validated hours of curriculum have not been established.
2. Independently author and review Vietnamese explanations, contrastive pronunciation support and localized UI. Test with Vietnamese and English beginner cohorts.
3. Connect optional speech transcription and open conversation through consent-bound server providers; add validated intelligibility rubrics. Never infer tone accuracy from transcript correctness. Add request budgets, error recovery and deletion controls before cloud voice.
4. Add licensed authentic media, persistent segment/phrase saving, unfamiliar-speaker transfer tasks and assessment rubrics. Local video/SRT import is already usable; automatic transcription, streaming-site import and a licensed library are not connected.
5. Publish intermediate and advanced functional curricula, social nuance and professional registers, then verified versioned HSK mappings and externally meaningful assessments. No readiness score should precede sufficient reviewed evidence.
6. Add accounts, tested migrations, encrypted transport, server backups, multi-device conflict handling, operational monitoring, paid plans and support only with a production security/privacy review.

## Commercial decision

A real personal-learning foundation is delivered. The complete premium commercial platform in the brief is not yet finished. Release quality for software behavior and visual presentation does not establish pedagogical efficacy or native-speaker accuracy. Promotion beyond a private pilot depends on the content and learner-validation gates above.
